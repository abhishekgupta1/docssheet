# docssheet — Project Context

A docs & cheat-sheet site built with Docusaurus, published at **docssheet.com**
(GitHub Pages + custom domain; `static/CNAME` + `url` in config). It was trimmed
down from a personal portfolio to just three working areas. This file records
that scope so future work adds content in the right place instead of re-growing
the removed sections.

## How this project is used

The site has exactly three working areas. There is no home/landing page — the
root URL (`/`) redirects to `/docs/intro`.

1. **Docs / Knowledge Base** (`docs/`, served at `/docs`, sidebar in
   `sidebars.js`)
   Long-form reference guides grouped by track (SDET, SRE, SDE, MBA, AI Skills).
   New topics get their own category folder following the existing pattern.

2. **Cheat Sheets** (`cheatsheets/`, served at `/cheatsheets`, its own docs
   plugin instance + `sidebarsCheatsheets.js`)
   One dense, scannable one-page reference per topic, cross-linked to its full
   guide in `/docs`. Flat, autogenerated sidebar.

3. **Learn** (navbar dropdown; pages in `src/pages/`)
   Client-side learning tools over the cheat-sheet catalogue:
   - `/roadmap` — suggested learning order per track (`roadmap.js`)
   - `/skills` — proficiency matrix (`skills.js`)
   - `/quiz` — spaced-repetition flashcards (`quiz.js`, `src/utils/srs.js`)
   - `/dashboard` — per-browser progress tracking with export/import
     (`dashboard.js`, `src/utils/progress.js`)
   - `/start` — "pick your focus" entry point (`start.js`)
   Data lives in `src/data/` (`topics.js`, `skills.js`, `quiz.js`).

### What was removed (do not re-add without being asked)

Projects, Articles/blog (`blog/`, `/articles`), Resume, Certifications, and the
marketing landing page + its sections (Hero/Services/Engagement/ContactCTA), plus
the Uses/Now/Contributing pages. The legal pages (`privacy`, `terms`,
`cookie-policy`, `disclaimer`) plus `about` and `contact` are kept — footer-
linked (the "Site" and "Legal" columns), not in the navbar — because AdSense
requires them.

### AdSense readiness

- Consent: Google Consent Mode v2 defaults are set in `docusaurus.config.js`
  `headTags` (all denied); `src/components/ConsentBanner` collects the choice
  and calls `gtag('consent','update',…)`. `CONSENT_REQUIRED` in
  `src/data/site.js` controls whether the visible strip shows. This is a
  first-party banner, NOT a Google-certified CMP — swap for a certified CMP or
  Google Privacy & messaging before serving ads in the EEA/UK.
- Ads stay off (`ADS_ENABLED = false`) until approved; then set `ADSENSE_CLIENT`
  and the real `pub-…` line in `static/ads.txt`.
- **Content-originality risk:** `docs/ai-skills/claude-masterclass/`
  (`transcript.md`, `course-overview.md`) is derived from a third-party
  (Udemy) course. Reproducing course material is exactly the "scraped /
  copyrighted content" AdSense prohibits — rewrite it as original notes or
  remove the folder before applying.

## Working agreement

- Default to adding/organizing **content** (docs, cheat sheets) inside the
  existing structure above.
- Do not refactor core components (`src/components/*`, `src/theme/*`,
  `docusaurus.config.js`, `sidebars*.js`, page files) unless explicitly asked —
  content changes should not turn into architecture changes.
- Keep the navbar to Docs / Cheat Sheets / Learn. New nav entries need a
  deliberate ask.
