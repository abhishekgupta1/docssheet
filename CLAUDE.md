# docssheet — Project Context

A docs & cheat-sheet site built with Docusaurus, **live at docssheet.com**
(GitHub Pages for the `abhishekgupta1/docssheet` repo + custom domain;
`static/CNAME` + `url` in config, deployed by `.github/workflows/deploy.yml` on
push to `main`).

**History:** this repo was seeded from a personal-portfolio Docusaurus site
(`../abhishekgupta1.github.io`, now kept separate for the portfolio) by importing
a curated subset of its content. Two import batches so far: the AdSense
"shortlist" (15 flagship guides + 8 cheat sheets), then a second batch bringing
the totals to **~42 guides + ~32 cheat sheets** across four tracks. The source
repo still holds more (the MBA/leadership library, the ~60-page
test-automation-tooling-landscape subtree, the blog) — import more from there if
needed; don't hand-write new topics.

## How this project is used

Two working areas. There is no landing page — `/` redirects to `/docs/intro`.

1. **Docs** (`docs/`, served at `/docs`, sidebar in `sidebars.js`)
   Long-form guides grouped by track: **SDET Skills**, **SRE Skills**,
   **SDE Skills**, **AI Skills** (categories are explicit in `sidebars.js`;
   items within each are `autogenerated` from the folder). Each topic is its
   own folder with a `_category_.json`. `docs/intro.md` is the docs landing
   page (hand-maintained — the track list + the SVG must be updated when tracks
   or major topics change).

2. **Cheat Sheets** (`cheatsheets/`, served at `/cheatsheets`, its own docs
   plugin instance + `sidebarsCheatsheets.js`, flat autogenerated sidebar)
   One dense one-page reference per topic, cross-linked to its full guide.
   `cheatsheets/intro.md` is a hand-maintained tile grid — add a tile when you
   add a sheet.

### Not imported (available in `../abhishekgupta1.github.io`)

MBA/leadership guides, the `test-automation-tooling-landscape` sub-topic pages
(only the top-level landscape guide is here), the blog, and the Learn tools
(`/roadmap`, `/skills`, `/quiz`, `/dashboard`, `/start` — their `src/pages/*`,
`src/data/{topics,skills,quiz}.js`, and the extra `src/components/*` were left
behind). `src/theme/MDXComponents.js` therefore registers only `AdSlot`; if you
import content that uses `<InterviewQuestions>`, `<KeyTakeaways>`, etc., copy
those components back and register them or the build fails.

Removed from the original portfolio and NOT to be re-added without being asked:
Projects, Articles, Resume, Certifications, the marketing landing page. The
legal/info pages (`about`, `contact`, `privacy`, `terms`, `cookie-policy`,
`disclaimer`) are kept — footer-linked (Site + Legal columns), not in the
navbar — because AdSense requires them.

### AdSense state

- Site is in AdSense **"Requires review"** — publisher ID `ca-pub-1394375154476572`.
- The `adsbygoogle` loader is emitted site-wide whenever `ADSENSE_CLIENT` is a
  real ID (`ADSENSE_ON` in `docusaurus.config.js`) — this is the verification
  hook. `static/ads.txt` carries the matching `DIRECT` line.
- **`ADS_ENABLED` in `src/data/site.js` is still `false`** → every `<AdSlot>`
  renders nothing. Flip it to `true` (and add ad units) only after approval.
- Consent: Google Consent Mode v2 defaults (all denied) in `headTags`;
  `src/components/ConsentBanner` collects the choice. This is a first-party
  banner, NOT a Google-certified CMP — swap for a certified CMP / Google
  Privacy & messaging before serving ads in the EEA/UK.
- `onBrokenLinks: 'throw'` — any broken internal link fails the build. When
  importing content, de-link references to pages you didn't import.

## Working agreement

- Default to adding/organizing **content** (docs, cheat sheets) by importing
  from `../abhishekgupta1.github.io` into the existing structure.
- Don't refactor core components (`src/components/*`, `src/theme/*`,
  `docusaurus.config.js`, `sidebars*.js`, page files) unless asked.
- Keep the navbar to **Docs / Cheat Sheets**. New nav entries need a deliberate
  ask.
- Planning docs live in `Plan/` — `GO-LIVE.md` (hosting steps), `NEXT-SESSION.md`
  (handoff), `docssheet-launch-spec.md` / `-plan.md`, `adsense-content-shortlist.md`.
