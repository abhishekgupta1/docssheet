# Docs

The **docssheet** docs are long-form guides that build the mental model for a
topic — what it is, why it works the way it does, worked examples, common
mistakes, and how it shows up in interviews and on the job. They span
**Test Automation (SDET)**, **Site Reliability Engineering (SRE)**, and
**Software Development (SDE)**.

## Categories

- **SDET Skills** — Test automation, quality engineering, and SDET practices (e.g. Playwright, SQL, the tooling landscape)
- **SRE Skills** — Observability, incident response, cloud, and reliability practices (e.g. Kubernetes, AWS, Terraform, OpenTelemetry)
- **SDE Skills** — Software development topics and patterns (e.g. Python, Git, Docker, Clean Architecture)

Browse the sidebar to explore each category, or jump to the matching
[cheat sheet](/cheatsheets) when you just need the syntax.
